# AI Health Assistant

Monitors your Garmin health metrics daily, cross-references your Google Calendar, and uses Claude AI to detect early signs of illness, overtraining, or recovery deficits — then notifies you automatically via Slack, email, or push notification.

## What it monitors

| Metric | Source |
|--------|--------|
| Sleep score, duration & stages (deep/REM/light) | Garmin Connect |
| Your sleep notes (notes you enter in Garmin) | Garmin Connect |
| HRV — last night + 5-day avg + status | Garmin Connect |
| Resting heart rate | Garmin Connect |
| Overnight heart rate (min/avg/max) | Garmin Connect |
| Body battery (peak) | Garmin Connect |
| Average stress score | Garmin Connect |
| Recent activities (type, duration, load) | Garmin Connect |
| Recent & upcoming calendar events | Google Calendar |

Each day it compares your metrics against your personal 14-day rolling baseline and flags deviations.

## How it alerts you

| Status | Meaning | Notification priority |
|--------|---------|----------------------|
| ✅ HEALTHY | All metrics normal | Silent (optional) |
| 👀 MONITOR | Minor deviation, worth watching | Standard |
| 🟡 EASY\_DAY | Recovery deficit — train lightly | Standard |
| 🔴 REST\_DAY | Multiple warning signs — rest today | High |
| 🚨 SEEK\_CARE | Possible illness — consider seeing a doctor | Urgent |

Notifications are sent via any combination of:
- **Slack** — DM or private channel via incoming webhook
- **Email** — full detailed report with metrics, observations, and recommendations
- **ntfy.sh** — push notification to your phone (free app, no account needed)

## How it runs automatically

Uses **GitHub Actions** on a daily cron schedule. No server, no infrastructure, no management — set up once and it runs every morning.

```
Every morning → GitHub pulls your Garmin data → fetches calendar → Claude analyses everything → you get notified
```

## Setup

### 1. Fork this repository

Fork to your own GitHub account so you can add secrets and enable Actions.

### 2. Add GitHub Secrets

Go to: **Settings → Secrets and variables → Actions → New repository secret**

**Required:**

| Secret | Value |
|--------|-------|
| `GARMIN_EMAIL` | Your Garmin Connect email |
| `GARMIN_PASSWORD` | Your Garmin Connect password |
| `ANTHROPIC_API_KEY` | Your Anthropic API key (get one at console.anthropic.com) |

**Slack (recommended):**

| Secret | Value |
|--------|-------|
| `SLACK_WEBHOOK_URL` | Incoming webhook URL — see [Slack docs](https://api.slack.com/messaging/webhooks) |

Create a Slack app, enable Incoming Webhooks, and point it at your DM channel or a private `#health` channel.

**Email (optional):**

| Secret | Value |
|--------|-------|
| `NOTIFY_EMAIL` | Address to receive reports |
| `SMTP_HOST` | e.g. `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | Your sending email |
| `SMTP_PASSWORD` | App password (Gmail: enable 2FA then create an [App Password](https://support.google.com/accounts/answer/185833)) |

**ntfy.sh push notifications (optional):**

| Secret | Value |
|--------|-------|
| `NTFY_TOPIC` | A unique topic name, e.g. `healthcheck-yourname-abc123` |

Install the [ntfy app](https://ntfy.sh) on your phone and subscribe to your topic.

**Google Calendar (optional):**

| Secret | Value |
|--------|-------|
| `GOOGLE_CALENDAR_CREDENTIALS` | JSON from Google Cloud Console |
| `GOOGLE_CALENDAR_TOKEN` | Generated by `scripts/setup_google_auth.py` |

To set up Google Calendar:
1. Go to [Google Cloud Console](https://console.cloud.google.com), create a project, enable the Calendar API, and download `credentials.json` (OAuth 2.0 Desktop app type)
2. Run locally: `python scripts/setup_google_auth.py`
3. Copy the two printed JSON values into GitHub Secrets

### 3. Enable GitHub Actions

Go to the **Actions** tab in your fork and click *"I understand my workflows, go ahead and enable them"*.

### 4. Adjust the schedule (optional)

Edit `.github/workflows/daily_health_check.yml` and change the cron line. Default is 8:00 AM UTC.

```yaml
- cron: '0 8 * * *'   # 8 AM UTC
- cron: '0 7 * * *'   # 7 AM UTC
- cron: '0 14 * * *'  # 6 AM US Pacific
- cron: '0 22 * * *'  # 8 AM AEST
```

Use [crontab.guru](https://crontab.guru) to find the right time.

### 5. Test it

Go to **Actions → Daily Health Check → Run workflow** to trigger a manual run and verify everything works before the scheduled run.

## Running locally

```bash
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your credentials
python main.py
```

## Notes

- **Garmin MFA:** Automated login requires MFA to be disabled on your Garmin account. Alternatively, create a dedicated Garmin account without MFA and share it with your main account's data.
- **Data timing:** The tool analyses yesterday's completed data. Run it after your watch has synced (usually within minutes of waking if your phone is nearby).
- **Garmin token caching:** Auth tokens are cached in GitHub Actions cache to avoid re-authenticating every day.
- **Notify on healthy:** By default, no notification is sent when status is HEALTHY. Set the `NOTIFY_ON_HEALTHY` Actions variable to `true` to receive a daily report regardless.
